# Storylines

Built: **A. One returned laptop.** A single request (`event-123`) travels the system from return desk to email; a route strip tracks each stop, and every mechanism appears at the moment that request needs it. Chosen because the source's failures are all concrete events on that one path.

Not built:
- B. Crash-test bench: each concept opens by breaking the system, then adds the mechanism that survives it.
- C. Decision ledger: eight entries with the choice, the alternative and the price, in source order.
